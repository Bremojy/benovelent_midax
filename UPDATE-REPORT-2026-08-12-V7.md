# Benovelent MIDAX V7 — Portal redesign

## Purpose
V7 is a visual/product redesign built directly from V6. Existing backend, authentication, accounts, data-integrity, carousel, Cloudinary, feedback, CORS and PWA fixes are retained.

## Portal redesign
- SuperAdmin dashboard rebuilt around a governance control room: live health, integrity signals, administrators, finance, communications and direct control tools.
- Admin dashboard rebuilt around an operations workspace: membership pulse, support, finance, communication, recent registrations and quick actions.
- Member dashboard rebuilt around a welcoming personal space: profile completion, community pulse, personal activity, accounts, dependants, support, chat and announcements.
- Shared V7 design language: large contextual hero, KPI surfaces, activity lists, direct-action cards, live signals, responsive mobile layout and role-specific visual accents.
- Global sidebar/topbar refreshed to match the new dashboard composition.

## Compatibility
No new runtime dependency was introduced. Existing V6 routes and services are reused.
