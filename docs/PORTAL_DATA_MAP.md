# Benevolent MIDAX Portal Data Map

## Navigation principle

The portal keeps the primary navigation compact. Related functions are grouped into section hub pages, and the hub contains the detailed subpages. Existing direct routes remain available for bookmarks and backwards compatibility.

## Member

- `/member` — Dashboard
- `/member/account` — My Account
  - `/member/profile` — Profile and membership documents
  - `/member/dependents` — Dependents
  - `/member/settings` — Security/account settings
- `/member/money` — Money & Contributions
  - `/member/accounts` — Accounts
  - `/member/contributions` — Contributions (legacy direct route retained)
  - `/member/mpesa-records` — M-PESA records
- `/member/support-center` — Support & Claims
  - `/member/support` — Request support / support history
  - `/member/claims` — Claims
  - `/member/benefits` — Benefits
- `/member/community` — Community
  - `/member/messages` — Chat
  - `/member/announcements` — Announcements
  - `/member/notifications` — Notifications
  - `/member/polls` — Polls
  - `/member/feedback` — Feedback
- `/member/help` — Help & Guide
  - `/member/guide` — User guide
  - `/contact` — Public contact route
- `/member/settings` — Portal settings

## Compatibility

The application continues to expose detailed legacy/direct routes so existing bookmarks and internal links do not need to be removed during the navigation consolidation. The sidebar is the compact entry point; section pages are the organized discovery layer.
