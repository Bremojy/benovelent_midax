# Benovelent MIDAX V7 — PWA & Portal redesign

V7 keeps the V6 PWA foundation and introduces a deeper role-based portal redesign. The PWA cache is versioned to v7 so deployed clients refresh the new portal experience.

## Visual system
- SuperAdmin: governance / intelligence / control
- Admin: operations / people / action
- Member: community / compassion / support

## PWA
- App name: Benovelent MIDAX
- Compact install experience remains available through the portal install control.
- Existing family/community icon assets from V6 are retained.
- Service-worker cache is now `benovelent-shell-v7`.
